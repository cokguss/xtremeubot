# XtremeBot — BloodSkill

Landing page & dokumentasi resmi **XtremeBot**, userbot Telegram tingkat dewa dengan 149+ modul, broadcast 24/7, AI assistant, anti-spam, dan fitur premium lainnya. Dibangun sebagai halaman statis tunggal dengan HTML, CSS, dan JavaScript vanilla murni.

## ✨ Fitur

- **149+ modul siap pakai.** Ekosistem perintah lengkap untuk otomatisasi, moderasi, dan produktivitas di Telegram.
- **Broadcast 24/7.** Pengiriman pesan massal nonstop dengan jadwal dan kontrol penuh.
- **AI assistant.** Asisten berbasis AI yang terintegrasi langsung ke dalam userbot.
- **Anti-spam & keamanan.** Proteksi bawaan terhadap spam dan aktivitas mencurigakan.
- **UI industrial brutalist CRT.** Estetika terminal taktis dengan efek scanline, grain, dan partikel latar.
- **Tanpa dependensi build.** Satu berkas HTML statis — langsung buka di browser atau unggah ke hosting apa pun.

## 🚀 Menjalankan Secara Lokal

Cukup buka berkas HTML secara langsung:

```bash
# Opsi 1: buka langsung di browser
start xtremebot.html

# Opsi 2: sajikan lewat server statis lokal (mis. Python)
python -m http.server 8080
```

Lalu buka `http://localhost:8080/xtremebot.html`.
